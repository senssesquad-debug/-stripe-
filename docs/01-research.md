# Этап 1 — Research: источники данных, API, ограничения

Дата исследования: **8 ноября 2026**. Всё, что помечено **[проверено вживую]**, было
запрошено из этой среды разработки в этот день. Всё, что помечено **[по документации]**,
взято из официальной документации/условий и должно быть перепроверено перед запуском —
условия провайдеров меняются.

## 0. Ключевые выводы (TL;DR)

1. **Универсального API «все события Кипра» не существует.** Ни один глобальный
   агрегатор (Ticketmaster, Eventbrite, Bandsintown, Songkick, Meetup) не даёт полного
   и бесплатного покрытия Кипра. Покрытие строится из многих источников + организаторов,
   которые сами добавляют события (это главный рычаг роста покрытия, см. `05-product-strategy.md`).
2. **Лучший найденный бесплатный официальный источник событий** — публичный REST API
   календаря на **visitcyprus.com** (Deputy Ministry of Tourism, плагин The Events
   Calendar): `GET /wp-json/tribe/events/v1/events`. [проверено вживую] На 08.11.2026 —
   18 предстоящих событий (спорт, классическая музыка, фестивали) со структурированными
   датами, часовым поясом, ценой, площадкой. Покрытие узкое (официальные/крупные события),
   координат площадок нет — нужен геокодинг.
3. **Google Places нельзя использовать как собственную базу мест.** Условия Google Maps
   Platform запрещают хранить контент Places (кроме `place_id` и временно lat/lng до 30 дней).
   Для клиентов из ЕЭЗ (Кипр — ЕЭЗ) с 8 июля 2025 действуют EEA-условия: контент Places
   API (кроме `place_id`, lat, lng) **нельзя показывать вместе с любой картой, включая Google**.
   → Архитектурное решение: базовый слой мест — **OpenStreetMap (ODbL)**, Google Places —
   «живое» обогащение на экране деталей (рейтинг, фото, часы), без кеширования контента и
   без карты на том же экране.
4. **Keyless-источники, которые реально работают** [проверено вживую]: visitcyprus.com
   events API, MET Norway (погода), Wikidata SPARQL (музеи, исторические места — 53 музея на
   Кипре), Nominatim (геокодинг с жёсткими лимитами), OpenStreetMap (через Overpass —
   в этой песочнице заблокирован egress-прокси, в продакшене доступен).
5. **Нельзя**: парсить Facebook/Instagram события (публичного API нет с 2018), обходить
   защиту soldoutticketbox.com (robots.txt отдаёт 403 боту — это сигнал «не надо»),
   использовать сайты с `Disallow: /` для нашего user-agent.

## 1. Места и заведения

### 1.1 Google Maps Platform / Places API (New)

| Вопрос | Ответ |
|---|---|
| Доступность | Да, глобально, включая Кипр. Требуется биллинг-аккаунт. [по документации] |
| Бесплатный тариф | С 1 марта 2025 вместо кредита $200 — бесплатные лимиты **на каждый SKU в месяц**: Essentials 10 000, Pro 5 000, Enterprise 1 000 вызовов. Лимиты не суммируются между SKU. [по документации] |
| Цена сверх лимита | Зависит от SKU и полей (field mask). Text Search Pro — ориентировочно ~$32 / 1000 (сторонний источник, проверить по официальному прайсу). Поля «атмосферы»/отзывов поднимают SKU до Enterprise. |
| Хранение | Разрешено хранить `place_id`. lat/lng — кешировать не более 30 дней подряд. Прочий контент (название, рейтинг, отзывы, фото, часы) — **не хранить** в своей БД. [по документации] |
| EEA (Кипр) | Для проектов с биллингом в ЕЭЗ, созданных после 08.07.2025: контент Places API, кроме `place_id`/lat/lng, нельзя использовать с любой картой (включая Google). Исключение — **Places UI Kit** (готовые компоненты Google). [по документации] |
| Атрибуция | Обязательна («Google Maps»/логотип) при показе контента Places. |

**Решение для passtra:**
- `place_id` хранится как внешний идентификатор места (матчинг OSM ↔ Google).
- Рейтинг/фото/часы Google запрашиваются сервером «вживую» при открытии карточки,
  через field mask (минимальный SKU), с атрибуцией, на экране без карты. Ключ — только на сервере.
- Ранжирование ленты не опирается на сохранённые рейтинги Google (хранить нельзя);
  используется собственный сигнал популярности + рейтинги пользователей passtra.
- Если в будущем нужен Google-контент рядом с картой — интегрировать нативный Places UI Kit.
- Карта в приложении: `react-native-maps` (Apple Maps на iOS, Google Maps SDK на Android)
  с нашими маркерами (OSM + события) — это разрешено.

### 1.2 OpenStreetMap (ODbL)

- Бесплатно, можно хранить, индексировать, объединять. Лицензия **ODbL**: обязательна
  атрибуция «© OpenStreetMap contributors»; производная *база данных*, если её публично
  распространять, должна быть под ODbL. Приложение — это «produced work»: нужна атрибуция.
  Мы храним OSM-записи отдельным слоем (`source_records`) со ссылкой, не смешивая с
  проприетарным контентом в одну таблицу без маркировки.
- Отличное покрытие практических мест: аптеки, банкоматы, заправки, EV-зарядки, почта,
  пляжи, смотровые площадки, тропы, музеи, кафе/рестораны/бары.
- Доступ: **Overpass API** (публичный overpass-api.de — лимит ~10k запросов/сутки и 1 ГБ/сутки;
  для продакшена рекомендован свой инстанс Overpass или импорт PBF-выгрузки Geofabrik).
  [проверено вживую] Из этой песочницы overpass-api.de и download.geofabrik.de недоступны —
  egress-прокси закрывает туннель (это ограничение песочницы, не сервиса). Коннектор
  поддерживает настраиваемый endpoint.
- Для локальной проверки в этой среде использовался OSM API `api/0.6/map.json` на
  нескольких маленьких тайлах (тот же формат элементов). В продакшене OSM API для этого
  **не использовать** — его политика допускает только редактирование/лёгкое чтение.

### 1.3 Wikidata (CC0)

- [проверено вживую] SPARQL `query.wikidata.org` работает; 53 объекта «музей» на Кипре.
- CC0 — без ограничений. Хорошо для музеев, археологических памятников, монастырей,
  замков, смотровых площадок; есть ссылки на Wikimedia Commons (фото с лицензиями).

### 1.4 Геокодинг

- **Nominatim** (OSM) [проверено вживую — доступен]: максимум 1 запрос/сек, обязателен
  идентифицирующий User-Agent, обязательное кеширование, без массового геокодинга.
  Используется только для адресов событий без координат, с кешем в БД.
- Google Geocoding API — опционально (ключ), те же ограничения хранения lat/lng (30 дней).

### 2.1 Обобщённый «легальный веб-коннектор»

Для сайтов без API реализован коннектор, который:
1. Перед каждым запросом проверяет `robots.txt` (корректный разбор групп `User-agent`,
   `Allow`/`Disallow`, wildcard `*` и `$`, `Crawl-delay`) — живые примеры выше показали,
   что наивный поиск строки `Disallow: /` даёт ложные срабатывания;
2. Читает **только структурированные данные, которые сайт сам публикует для машин**:
   schema.org `Event` в JSON-LD, iCal (`.ics`), RSS/Atom, публичные REST-endpoint'ы;
3. Не выполняет JavaScript, не логинится, не обходит CAPTCHA/WAF, соблюдает Crawl-delay
   и собственный лимит 1 запрос / 5 сек на домен;
4. Источник нельзя включить в админке, пока не отмечено «Условия использования проверены»
   (поле `terms_reviewed_at` + ссылка на условия).

### 2.2 Почему нельзя обещать полноту

Значительная часть кипрской афиши (клубы, рейвы, небольшие концерты) публикуется только
в Instagram/Facebook и на sold-out-платформах без API. Легально эти данные можно получить
только от самих организаторов → **кабинет организатора / форма добавления события**
(реализовано) и партнёрские фиды от билетных сервисов.

## 3. Погода

- **MET Norway Locationforecast 2.0** [проверено вживую]: бесплатно, коммерческое
  использование разрешено (CC BY 4.0 / NLOD), обязательны атрибуция и идентифицирующий
  User-Agent, нужно кешировать по заголовку `Expires`/`If-Modified-Since`. SLA нет.
  **Выбран по умолчанию.**
- Open-Meteo: бесплатен только для некоммерческого использования; [проверено вживую]
  из песочницы получен 429. Для коммерции — платный тариф. Не используется по умолчанию.

## 4. Маршруты и навигация

- Открытие навигации — через URL-схемы Google Maps (`https://www.google.com/maps/dir/?api=1&destination=…`)
  и Apple Maps (`https://maps.apple.com/?daddr=…`) — бесплатно, ключ не нужен.
- Время в пути в приложении: по умолчанию **оценка** (расстояние по прямой × коэффициент
  извилистости / скорость режима), всегда помечается как «≈». При наличии ключа Google
  Routes API — точное время (Essentials-SKU, 10k бесплатно/мес).

## 5. Практические данные Кипра

- **Дежурные аптеки**: официальный открытый датасет на data.gov.cy не подтверждён;
  CKAN-endpoint `/api/3/action/...` вернул 404 [проверено вживую]. Агрегаторы
  (farmakeia.com.cy и др.) — сторонние сайты, без подтверждённой лицензии. → Показываем
  аптеки из OSM с часами работы и ссылкой «проверить дежурные аптеки» на официальный
  ресурс Министерства здравоохранения. Не выдаём «дежурная сейчас» без надёжного источника.

## 6. AI

- Используется **Claude API** (Anthropic) только для: интерпретации запроса на
  естественном языке → структурированные фильтры (tool use со строгой JSON-схемой),
  классификации категорий входящих событий. **AI не генерирует результаты поиска,
  даты, цены, адреса.** При отсутствии ключа работает детерминированный многоязычный
  парсер запросов (en/el/ru).
- Объяснения рекомендаций строятся из шаблонов по реальным признакам (расстояние,
  категория, время), а не генерируются моделью.

## 7. Юридические ограничения (резюме)

| Тема | Что учитываем |
|---|---|
| GDPR | Минимизация данных; анонимное использование без регистрации; геолокация только в запросе, **история перемещений не хранится**; экспорт и удаление аккаунта; срок хранения взаимодействий 180 дней |
| Google Maps Platform | Не хранить контент Places; EEA-условия о картах; атрибуция; ключи только на сервере |
| ODbL | Атрибуция OSM в приложении и на сайте; OSM-данные отдельным слоем |
| Авторское право | Описания событий — короткие выдержки + ссылка на первоисточник; изображения — только с разрешённых источников (API с лицензией на показ, Wikimedia Commons с атрибуцией, загрузки организаторов) |
| Скрейпинг | robots.txt, Terms of Use, без обхода защиты, низкая частота, идентифицирующий User-Agent |
| Казино | Кипр: лицензированные казино 18+ (регулятор — Cyprus Gaming and Casino Supervision Commission); категория помечается 18+ и скрывается для пользователей, указавших возраст < 18; **требует проверки правил App Store/Google Play для гемблинг-контента** |
| Реклама | Помечается «Sponsored», не влияет на органическую выдачу (отдельный слот) |
| App Store / Google Play | Purpose strings для геолокации, Privacy Nutrition Label / Data safety, удаление аккаунта в приложении (требование Apple 5.1.1(v)) |
