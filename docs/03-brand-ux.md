# Этап 3 — Бренд passtra и UX

## 1. Идентичность

- **Название:** passtra — всегда строчными, в том числе в начале предложения и в сторах.
- **Обещание:** «What's happening around you, right now.» — без привязки к Кипру в названии;
  Кипр — первая страна, архитектура и бренд рассчитаны на расширение.
- **Характер:** современный, международный, надёжный, повседневный. Тихий интерфейс,
  громкий контент.

### Знак
Строчная **p**, чья «чаша» — кольцо геолокации с точкой «вы здесь». Читается и как инициал,
и как «места вокруг вас». Источник — `brand/passtra-mark.svg` (цвет через `currentColor`),
иконка — `brand/passtra-icon.svg`. PNG генерируются скриптом `node brand/scripts/render.mjs`
(Chromium/Playwright), шрифт встраивается в рендер.

| Файл | Назначение |
|---|---|
| `icon.png` 1024² | iOS / App Store (без прозрачности, маску накладывает ОС) |
| `android-icon-foreground/background/monochrome.png` | Android adaptive + themed icon (знак в безопасной зоне 66%) |
| `splash-icon.png` | Splash (знак на фоне `#1769E8`) |
| `favicon.png` | Web / админка |
| `wordmark-blue/white.png`, `lockup-horizontal.png` | Шапки, сайт, промо |
| `play-feature-graphic.png` 1024×500 | Google Play |

Правила: минимальное поле вокруг знака — ½ диаметра кольца; не вращать, не обводить,
не добавлять тени/градиенты; на фото — только на белой или синей плашке.

### Цвета (`packages/brand`)

| Токен | Светлая | Тёмная | Использование |
|---|---|---|---|
| primary | `#1769E8` | `#1769E8` | Кнопки, активная вкладка, выделение |
| primaryText | `#1769E8` | `#6EA3FF` | Ссылки и синий текст (AA-контраст на тёмном фоне) |
| primary dark | `#0D47A1` | — | Wordmark, заголовки промо |
| primarySoft | `#EAF2FF` | `#13254A` | Чипы, подложки бейджей |
| background | `#FFFFFF` | `#0A1020` | Фон экранов |
| surface / surfaceAlt | `#F7F9FC` / `#F1F4F9` | `#121A2B` / `#1A2438` | Карточки, поля, скелетоны |
| border | `#E3E8F0` | `#263248` | Разделители |
| text / secondary / tertiary | `#0B1526` / `#5B6576` / `#8A93A3` | `#F2F5FA` / `#A9B3C4` / `#8A93A3` | Иерархия текста |

Контраст: белый на `#1769E8` = 5.0:1 (AA для текста кнопок). Градиенты не используются,
кроме едва заметной подложки промо-графики.

### Типографика
**Manrope** (OFL) — интерфейсный шрифт: латиница, **греческий и кириллица** (проверено по cmap шрифта).
Wordmark «passtra» набран **Plus Jakarta Sans ExtraBold** и используется только как изображение —
в Plus Jakarta Sans нет греческих и кириллических глифов, поэтому для текста интерфейса он не годится
(обнаружено при проверке UI: «Ελληνικά»/«Русский» падали в системный serif).
Шкала: Display 30/36 ExtraBold, Title 22/28 Bold, Headline 17/22 Bold, Body 15/21 Medium,
Callout 14/19, Caption 12.5/16, Micro 11/13 Bold (бейджи). Отрицательный трекинг на крупных
кеглях. Поддерживается Dynamic Type (масштабирование системным размером шрифта).

### Форма и движение
Скругления 6/10/14/20/28; карточки — 20, кнопки — pill. Тени мягкие (opacity 0.07).
Анимации 150/220/320 мс: появление карточек, нажатие (scale 0.98), переключение
карта/список. Уважение к «Уменьшить движение» в настройках ОС.

## 2. Информационная архитектура

Вкладки: **Today · Explore · Map · Saved · Profile** (нижняя навигация — досягаемость одной рукой).

| Экран | Содержание |
|---|---|
| Onboarding (3 шага, всё можно пропустить) | 1) ценность + язык; 2) интересы (12 чипов); 3) запрос геолокации с объяснением «зачем», альтернатива — выбрать город |
| **Today** | Шапка: город (смена), погода, поиск, уведомления, профиль. «Today near you / What's happening around you?». Кнопки **Surprise me** и **Plan my day**. Секции: For you, Happening today, Right now, Tonight, This weekend, Near you, Free things to do, Hidden gems, Popular right now (появляется только при реальных данных) |
| **Explore** | Explore the City: выбор города, группы интересов, фильтры (радиус 1/3/5/10/25/50 км, открыто сейчас, бесплатно, время), список |
| **Map** | Карта + маркеры (события/места), фильтр-чипы, переключатель карта/список, нижняя карточка объекта, «искать в этой области» |
| **Saved** | Сохранённые места и события (локально без аккаунта, синхронизация после входа), списки |
| **Profile** | Вход/аккаунт, язык, интересы, бюджет, возраст (необязательно), уведомления (частота, тихие часы, категории), приватность (персонализация вкл/выкл, экспорт, удаление аккаунта), источники данных и атрибуции, для организаторов — «Добавить событие» |
| Детали события | Фото (если лицензия позволяет), категория, **время в часовом поясе события** («время не объявлено» если неизвестно; «время не подтверждено» при конфликте), цена (или «цена не указана»), площадка, расстояние, кнопки: билеты, маршрут (Google/Apple Maps), поделиться, сохранить, сообщить об ошибке/отмене. Блок **«Откуда эти данные»**: источники, ссылки, «проверено N мин назад», статус достоверности, расхождения |
| Детали места | Часы работы (открыто/закрыто, до скольки), бесплатно (с пометкой «обычно бесплатно», если это знание о категории), контакты, предстоящие события здесь, отзывы passtra, **живые данные Google** (рейтинг) — отдельным блоком без карты, с атрибуцией |
| Поиск | Поле ввода на естественном языке, подсказки-примеры, «Мы поняли так: Концерты · Лимассол · Выходные» (редактируемые чипы), результаты |
| Surprise me | 3–4 разнообразных варианта с объяснением «почему» |
| Plan my day | Время начала/конца, бюджет, интересы, транспорт → таймлайн с перемещениями «≈ 12 мин пешком», пометки «часы не указаны», «цена неизвестна», дисклеймер |

## 3. Состояния (для каждого экрана)

| Состояние | Поведение |
|---|---|
| Загрузка | Скелетоны карточек той же формы (без спиннеров на весь экран) |
| Нет результатов | Иллюстрация-знак, объяснение причины и действие: расширить радиус, сменить время, убрать фильтр |
| Мало событий в районе | Честная плашка: «Пока мало событий… показываем только проверенные источники» + ссылка «Вы организатор? Добавьте событие» |
| Ошибка сети | Последние данные из кеша с меткой «обновлено в 14:32» + кнопка «Повторить»; без кеша — экран с повтором |
| Медленный интернет | Запросы с таймаутом, прогрессивная загрузка секций |
| Геолокация отклонена | Лента по выбранному городу; ненавязчивый баннер «Включить геолокацию» со ссылкой в настройки |
| Геолокация недоступна / вне зоны покрытия | Выбор города; сообщение «passtra пока работает на Кипре» |
| Событие отменено | Красный бейдж «Cancelled» в деталях; из лент и поиска исключается |
| Данные противоречат | Жёлтая плашка «Источники расходятся» с вариантами и источниками |
| DEMO-данные | Синяя метка DEMO на каждой карточке (только в режиме разработки) |
| Нет аккаунта | Всё работает; сохранение локально; вход предлагается только при синхронизации/отзывах/добавлении события |

## 4. Доступность
Контраст AA, размеры касания ≥ 44×44, подписи `accessibilityLabel` у иконок,
поддержка экранного диктора (VoiceOver/TalkBack), масштабирование шрифта, тёмная тема,
отсутствие информации, передаваемой только цветом (статусы дублируются текстом).
