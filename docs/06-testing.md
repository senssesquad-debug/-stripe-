**Найдено и исправлено благодаря живым данным** (фикстуры этого не ловили):
1. Геокодер ставил «Famagusta Nautical Club, Limassol» в Фамагусту (клуб переехал в Лимассол),
   а «Pissouri Beach, Geroskipou» — верно в Писсури при ошибочном городе в источнике. Теперь
   противоречие не решается автоматически: открытый конфликт, город по источнику, модератор выбирает.
2. Шрифт Plus Jakarta Sans не содержит греческих и кириллических глифов → интерфейс на el/ru
   падал в serif. Переход на Manrope (проверено по cmap шрифта).
3. Секция «Рядом» пропадала при заданных интересах (дедупликация после неглубокого ранжирования).
4. Планировщик дня ставил замок Лимассола без известных часов работы.
5. Планировщик источников не снимал блокировку после запуска (ошибка типов параметра SQL) и
   worker прерывал текущий прогон при остановке.

## 4. Что ещё НЕ проверено (нужны устройства/аккаунты)
| Что | Почему не здесь | Как проверить |
|---|---|---|
| Нативные сборки iOS/Android, карта react-native-maps | нет Xcode/Android SDK и аккаунтов | `eas build --profile preview`, TestFlight / Internal testing |
| Push-уведомления на устройстве | нужен EAS projectId и устройство | профиль development, «Уведомления» в профиле |
| Вход через Supabase | нет проекта Supabase | заполнить `EXPO_PUBLIC_SUPABASE_*` и `AUTH_*` |
| Живой вызов Claude API | нет ключа в среде | задать `ANTHROPIC_API_KEY`, `POST /v1/search` → `interpretation.engine = "ai"` |
| Ticketmaster, Eventbrite, Google Places | нет ключей | задать ключи; в админке «Run now» |
| Overpass по всей стране | egress песочницы закрывает overpass-api.de | в продакшене — стандартный режим `overpass` |
| Плохая сеть, разные экраны, VoiceOver/TalkBack | нужны устройства | чек-лист в `docs/release/release-checklist.md` |
| Нагрузочное тестирование | — | k6/Artillery на `/v1/feed/today` и `/v1/search` перед запуском |
